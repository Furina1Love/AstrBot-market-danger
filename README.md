## 这个插件源的初衷
只是想收入一些~~比较猎奇~~插件（包括未审核通过的插件），通过提交issue的方式自动化上传

你可以在这个插件源找到一些未经官方源审核的插件

## 如何使用这个插件源
- 打开AstrBot WebUI
- 点击左上角三横
- 在左侧找到“插件”并点击
- 在插件的页面中找到“插件市场”并点击
- 点击“默认插件源”的按钮
- 点击“+ 添加插件源”按钮
- 输入https://ghfast.top/https://raw.githubusercontent.com/Furina1Love/AstrBot-market-danger/refs/heads/main/package.json
- 点击保存即可
- 最后点击刚保存的插件源，就可以食用了
